Авторусь Сигнал для Windows
Версия из GitHub main — e4ec00d

1. Распакуй папку Signal из ZIP в новую папку. Если папка Signal уже есть,
   распакуй архив в отдельную папку, чтобы сохранить прежнюю установку.
2. Если старая админка запущена, нажми Ctrl+C в окне с веб-сервером PHP.
   PostgreSQL оставь запущенным. Скопируй прежний .env в новую папку
   Signal\laravel, рядом с файлом artisan. Вместе с ним сохранятся
   подключение к базе, ключ шифрования и прежние настройки входа.
3. Открой новое окно PowerShell и перейди в новую папку Signal\laravel.
   Если распаковал папку Signal прямо в домашнюю папку, выполни:

   Set-Location -LiteralPath "$env:USERPROFILE\Signal\laravel"
   $php = "$env:USERPROFILE\php84\php.exe"
   & $php artisan migrate

   Если Signal или PHP находятся в другом месте, укажи свой путь.
   Миграции добавят индексы поиска, таблицы учётных записей и журнал действий.
   Если ошибка упоминает pg_trgm, проверь наличие расширения в PostgreSQL.
   Для установки расширения в существующей базе нужны права CREATE на базе;
   администратор может установить pg_trgm заранее.

4. После успешной миграции запусти:

   & $php artisan serve --host=127.0.0.1 --port=8000

   Оставь окно открытым и перейди на http://127.0.0.1:8000/admin.

Если личные аккаунты ещё не созданы, можно войти прежним общим паролем.
Чтобы включить вход по логину, создай первого администратора в разделе
«Учётные записи». После его создания общий пароль перестанет действовать.
Если личные аккаунты уже есть в базе, используй свой логин и пароль.

В архиве есть зависимости приложения. На компьютере нужны PHP 8.4 и
PostgreSQL, как в предыдущей установке. Для этого режима не нужны Composer
и Docker. Запуск через artisan serve открывает админку. Автоматическая
доставка и планировщик запускаются отдельно.

В архив не входят .env, данные базы и пароли.
